# Resume_Rag

## Project Overview

Creating a RAG system for generating ATS friendly 100/100 resumes for autonoumous submission. 

## Requirements
 
|            | Minimum                                   | Recommended                                              |
| ---------- | ----------------------------------------- | ------------------------------------------------------- |
| OS         | Windows 10+, macOS 12+, or Linux (64-bit) | same                                                    |
| Python     | 3.10+                                     | 3.11 - 3.14                                            |
| RAM        | 8 GB                                      | 16 GB+                                                  |
| GPU        | none — runs on CPU                         | any NVIDIA (CUDA), recent AMD (RX 6000+), Apple Silicon |
| Disk       | ~5 GB free (one small model)              | 20 GB+ if you try larger models                        |
| Network    | needed for the first model download       | —                                                       |
